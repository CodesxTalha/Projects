      How it works
      
    
        
      
      1. When you copy in Figma, the layers go onto your clipboard in Figma's own format. This page reads that data directly: no plugin, no account, nothing uploaded.
        2. 
      
      2. Auto layout becomes flexbox (direction, gap, padding, alignment, hug, fill and fixed sizes). Other frames use absolute positioning with your constraints, so resizing behaves like in Figma.
        3. 
      
      3. Each layer gets the right element: header, nav, section, h1–h6, p, button, a, input, ul/li, img or inline svg, using layer names and structure.
        4. 
      
      4. Class names follow BEM and come from your layer names (.hero__title). Components share one class, and variants become modifiers (.button--secondary). Colours used more than once become CSS variables.
        5. 
    
      
    
      For the best result
      
    
        
      
      • Name your layers: "Header", "Nav", "Card", "Button", "Email field". Default names like "Frame 12" get a name from what the layer is.
        • 
      
      • Use auto layout. It becomes clean flexbox; absolute layouts can't reflow on small screens.
        • 
      
      • Images aren't part of Figma's copy data. Open a .fig file (File › Save local copy) to include them; otherwise they show as placeholders.
        • 
      
      • Responsive mode makes the page fluid: rows stack on phones, spacing and large text scale with the screen.
