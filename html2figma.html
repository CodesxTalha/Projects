      How it works

      1. Your page is rendered in a real browser frame, so the layout is exactly what a browser draws. With width on Auto, a design with its own fixed size (a 1080px post, a 1754px bill) gets a frame of exactly that size; a page that stretches to fit any window gets 1440. Height on Auto fits the content.
      2. Every element is measured: position, size, colours, gradients, borders, radii, shadows, text styles, images and SVG.
      3. That is turned into native Figma layers. Flex, grid and block flow become auto layout wherever Figma can reproduce it exactly; anything else is positioned absolutely.
      4. Copy puts the layers on your clipboard in the same format Figma uses for its own copy and paste. Press Ctrl + V in any Figma file.

      Good to know

      • Everything runs in your browser. Nothing is uploaded, except link pages which pass through a CORS proxy.
      • Fonts must exist in Figma. Google Fonts work everywhere; other fonts need to be installed on your computer.
      • Animations, hover states, video and canvas drawings are captured as they look at that moment.
      • React, Vue and other source files need to be built first. Drop the built folder, or copy the rendered HTML from your browser's developer tools.
      • Figma's paste format is not officially documented, so a future Figma update could change what pastes correctly.
